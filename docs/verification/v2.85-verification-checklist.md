# V2.85 Verification Checklist

Status: completed on 2026-06-16.

V2.85 Rust RPC domain module splitting is completed. It was a refactor-only service module-boundary slice. The current app has since removed legacy deterministic knowledge/remediation/cockpit RPCs, so this historical checklist now records the split pattern rather than the old method count.

## Scope

- `ServiceHost` RPC implementation moved out of `crates/service/src/lib.rs` into current domain files such as `service_host.rs`, `service_llm.rs`, `service_app_search.rs`, and service helper modules.
- `crates/service/src/lib.rs` keeps the public DTO and service envelope surface while becoming a small crate-root entrypoint.
- Protocol drift verification now scans split service implementation files for `handle_result` dispatch arms.
- `SUPPORTED_METHODS` remains in `crates/service/src/protocol.rs`; later cleanup removed legacy methods that no longer match current UI features.

## Non-goals

- No service protocol method or payload changes in the original V2.85 slice.
- No protocol version bump.
- No provider default calls.
- No write/apply path.
- No hidden task state.
- No scanner/catalog fact mutation.
- No script execution.
- No credential reads.
- No raw prompt/response/trace persistence.
- No cloud sync.
- No telemetry.
- No public distribution, signing, notarization, DMG, or ZIP work.
